# 銘柄比較PRO 長所・短所の補完（2026-11-20）

運営者の依頼（11/20）: 「長所・短所出てない銘柄は全チェックして追加してください」。
要点（直近期間の長所・短所）がある会社は、長所と短所を最低1つずつ出す。

対象と方法は 11/19 の監査（`docs/comparison-audit-2026-11-19/README.md`）と同じ。SEC の会社一覧の上場ティッカー 7,668 を
`scripts/research/comparison-audit/audit.mjs` で本番と同じサーバーコードに通し、`summarize-items.py` で数えた。比較に出る銘柄は 5,765。
修正前は origin/codex/research-preview（5ea7fc91）、修正後は claude/comparison-items-fill。SEC の数値は 11/20 に取り直したため、
修正前の数は 11/19 の表（長所0 466・短所0 678）と少し違う。銘柄ごとの結果は `items.csv`。

## 追加した要点（順番どおり）

1. 提出書類から読める短所・長所
   - 株主資本がマイナス: 同じ期末・同じ通貨の株主資本（親会社分、なければ非支配持分込み）が記載され、0 未満のとき。373 社
     （MO −22.25 億ドル、PM、ABBV など）。
   - 売上前四半期比: 前年同期の売上がなく、成長性を前四半期比で採点している会社だけ（採点と同じ数字）。長所 30・短所 21。
2. それでも短所（長所）がない会社は、その会社の採点項目のうち最も低い（高い）項目を「他の項目より低め（高め）」として、
   その項目の実際の数値つきで出す（例: 「収益性は他の項目より低め（営業利益率 4.0%）」）。印 `relative` 付き。
   - 使うのは採点済みの項目だけ。すでに反対側の要点を出した項目と、割安性（相手の銘柄で物差しが変わる）は使わない。
   - ほかの採点項目の少なくとも1つより低い（高い）ときだけ。採点項目が1つの会社には足さない。
   - 長所にするのは 5 点以上で、流動比率 1 倍未満の財務は長所にしない（KXIN: 流動比率 0.11 倍が 5.3 点になる例）。
3. 総合評価の文章の注意点は、基準による短所を先に使い、相対の短所はどちらの会社にも基準による短所がないときだけ。
4. キャッシュのキーを v13 に更新（保存済みの要点を作り直す）。

### 注意（監査で測れないもの）

株価は Twelve Data のクレジットを使うため監査外で、上場銘柄には合成の株価（約3か月 +1.0%、5.1 点）を入れている。相対の要点のうち
株価モメンタム（長所 446・短所 381）は本番では実際の株価で決まる。約3か月の株価が下がれば基準による短所「約3か月の株価 −x%」、
大きく上がって 7 点以上なら基準による長所になる。後者で、ほかの項目がすべて長所の会社（A, AA, HSBC, TSM など）は短所が出ないことがある。
