方法: `scripts/research/comparison-audit/audit.mjs` が本番と同じサーバーコード（lib/research/comparison-server.ts）で各ティッカーを評価。
「修正前」は origin/codex/research-preview（本番 main と同じ）、「修正後」はこのブランチ。SEC は毎秒 7 件以下・ディスクキャッシュ。
Twelve Data は参照リスト（/stocks）だけを使い、本番が送るシンボルで掲載を判定（修正前は BRK-B をそのまま送るので 404 と同じ扱い）。

- full: 割安性以外の 6 項目をすべて採点 / partial: 3 項目以上 / failing: 2 項目以下（「正確に測れない」）

## 修正

1. 種類株のシンボル: Twelve Data は BRK.B 形式で、BRK-B は 404（本番ログ 11/19: BRK-A, LEN-B, HEI-A, PBR-A）。上場の種類株 24 銘柄
   （BRK-A/B, BF-A/B, LEN-B, HEI-A, PBR-A, MKC-V など）で株価・予想PER・決算書が取れるようになる。株数×株価の P/S は種類株では使わない。
2. カナダの銀行など 10 月決算の四半期 6-K（1・4・7 月末）を読む。
3. inline XBRL の文書セット（文脈は表紙側、数値は別文書: BMO の _d2.htm）を読む。BUD・BCS・ALC など他の外国企業にも効く。
4. IFRS の銀行の「営業収益」（RevenueAndOperatingIncome: HSBC の売上高 2024 年 659 億ドルと一致）を、他の売上行がないときだけ売上とする。
5. 半期の 12 か月売上（年度＋今期半期−前年同半期）、前年同期のない半期は使わない（Ohmyhome）。
6. 背景ジョブの決算書（200 クレジット）の順番を毎日 1 社ずつ回す。同じ分の 2 社目以降が毎日飛ばされていた（本番ログ skipped=…:statements）。

本番だけで効くもの（監査では測れない）: 1 の予想PER・決算書、6。

## 値の正しさ（SEC 原本との照合）

`scripts/research/comparison-audit/spot-check.py`: 会計基準 × 提出書類 × 業種で層別に 184 銘柄を抽出し、比較が使った提出書類の
XBRL インスタンス（EDGAR）を別の実装で読み、売上・営業利益・前年同期の売上が同じ概念・同じ期間・同じ値かを確認。
第4四半期（年次−9か月）は 10-K と第3四半期 10-Q の両方を読んで確認。結果は `spot-check.jsonl`。

| 区分 | 確認 | 不一致 |
|---|---|---|
| US GAAP 10-Q | 25 | 0 |
| US GAAP 10-K（第4四半期） | 25 | 1 |
| US GAAP 20-F / 6-K / 40-F | 57 | 0 |
| IFRS 20-F / 6-K / 40-F / 10-Q | 73 | 0 |
| 古い期間（2010 年など） | 4 | 2 |
| 計 | 184 | 3 |

不一致 3 件はいずれも画面に数値が出ない銘柄（最新値未確認）:
- KRSA: 後の 10-Q が 2025 年 9 か月の営業損失を 22,322 ドル（元は 413.5 万ドル）と再掲しており、第4四半期が誤る。会社側の桁の誤り。
- BBD・BBDO: 2010 年の数値（銀行の売上の組み立てが原本と合わない）。最新期間がないため表示されない。

業種別（エネルギー・公益 / 金融 / 医薬 / テック / その他）でも上記以外の不一致はなし。

## 比べられない銘柄を候補に出さない（運営者の判断 11/19：案A）

決算の数字（売上・利益）がない、または本体の会社の数字しかない銘柄は、銘柄比較の検索候補に出さない。直接指定されたとき（古いリンク・API）は、
これまでの「比較できない銘柄」と同じ扱い（unknown-company）。背景ジョブはこれらに決算書のクレジットを使わない。画面の文言は変えない。

判定は確実なものだけ（lib/research/comparison-exclusions.ts）:
- 優先株・ワラント・ユニット・権利: SEC のティッカーの接尾辞（-PB, -WT, -UN, -RI など）、または Nasdaq の 5 文字で末尾 W/U/R かつ同じ会社に 4 文字の本体ティッカーがあるもの。
- SPAC: SIC 6770 で売上がない会社。ファンド・商品信託: SIC 6221 または SIC なしで、名前がファンド（ETF, Trust, Fund など）で売上がない会社。
  一覧（comparison-exclusions.json、`scripts/research/comparison-audit/excluded.py` で作成）は会社名つきで、合併して名前が変わった SPAC は自動で候補に戻る。

| 種類 | 外した上場ティッカー |
|---|---|
| SPAC（本体） | 305 |
| ファンド・ETF・商品信託 | 404 |
| 優先株 | 378 |
| ワラント | 371 |
| ユニット | 278 |
| 権利 | 113 |
| 計 | 1,849 |

外した後の「正確に測れない」は 941（上の 2,349 のうち 1,408 が外した銘柄）。普通株・種類株（BRK-B, MKC-V など）、名前に Trust を含む事業会社（ADAM など）は外さない。
