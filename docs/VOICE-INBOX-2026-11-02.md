# ボイスメモ → 受信箱(iPhoneのショートカットから直接送る)

2026-11-02 オーナー指示。ボイスメモの「共有」から、ショートカット経由で受信箱に音声を直接届ける。

## しくみ
- **受け取り口(11/3 直し)**: Railway の入り口は、この送り先への64KB超の送信を断る(「Maximum request body size 65536 exceeded」)ことが実機の確認で分かった。そのため、ファイル本体は保存先(R2)へ直接置き、監視サービスには小さな2回だけ送る。
  1. `POST /inbox/start`(ヘッダー `Authorization: Bearer <鍵>`)→ 返事は、保存先の短い期間だけ使える住所(文字だけ)。
  2. その住所へ `PUT`(本文はファイルそのもの)。
  3. `POST /inbox/finish`(同じヘッダー)→ 中身が音声か確かめ、受信箱へ入れる。音声でない・大きすぎるときは保存先から消す。
  - 送信の回数の制限は、1回の送信を1回と数える(start で数える)。終わらなかった送信は2時間で片づける。
  - 旧 `POST /inbox/upload`(multipart)は残してあるが、64KB以下しか通らない。
- **認証**: ログインではなく「受信箱の鍵」。`Authorization: Bearer <鍵>`。サーバーは鍵の**ハッシュ(SHA-256)だけ**を保存して比べる。合わないときは401を返し、何も保存しない。
- **鍵の発行**: 運営者だけの画面 `/research/inbox-key`(受信箱の下の「受信箱の鍵と送り先」から開く)。「新しく作る」で発行し、その場で1回だけ全文を表示(コピーボタンつき)。作り直すと、古い鍵はすぐ使えなくなる。鍵はログにも環境変数にも出さない。
- **受け取ったあと**: 音声だけ(m4a・mp4・mp3・wav)。拡張子ではなく**中身**で確認する(MP4は音声トラックのみ・動画トラックなし、MP3はフレーム、WAVはヘッダー)。大きさの上限と回数の制限は `scripts/research/voice_inbox_settings.json`(上限100MB、1分6回・1時間60回、鍵の間違いは10分に5回まで)。非公開のR2(`inbox/<uuid>.<拡張子>`)に保存し、受信箱に1件(NEW)追加。タイトルの初期値は、送られたファイル名、なければ録音日時。受信箱の中で、あとから変えられる。
- **公開しない**: 受信箱に入るだけ。ひとりごとや会員の画面には、自動で出ない。
- **返事**: ショートカットがそのまま通知に出せる、短い日本語のテキスト(例: 「受信箱に届きました。」「音声ファイルではありません。」「ファイルが大きすぎます(上限 100MB)。」「鍵が合いません。」「送信が多すぎます。少し待ってからもう一度送ってください。」)。
- **保存先に入れないとき**: 返事は短い日本語(「設定が、まだ終わっていません」「権限」「保存できませんでした」)。ログには、原因のコード(`r2-not-configured:<足りない変数の名前>`、`r2-auth-failed-403`、`r2-network-error`、`r2-put-failed-<状態>`)を残す。値は出さない。

## 監視サービス(Railway)に必要な設定
サイト側(Vercel)にすでにある、音声用のR2の4つを、`research-monitor-staging` にも**同じ名前で**入れる(値は秘密。チャットに貼らない)。
`DESK_MEDIA_R2_ACCOUNT_ID` / `DESK_MEDIA_R2_BUCKET` / `DESK_MEDIA_R2_ACCESS_KEY_ID` / `DESK_MEDIA_R2_SECRET_ACCESS_KEY`
足りないあいだ、送ると「設定が、まだ終わっていません」と返り、ログに足りない変数の名前が出る。

## ショートカット(オーナーが作る)
共有シートで受け取る → ①「URLの内容を取得」(URLは `/research/inbox-key` の①、POST、ヘッダー `Authorization` = `Bearer ` + 鍵)→ ②「URLの内容を取得」(URLは①の「URLの内容」、方法 PUT、本文はファイル=ショートカットの入力)→ ③「URLの内容を取得」(URLは②の送り先、POST、ヘッダーは①と同じ)→ 「通知を表示」(③の内容)。

## いまの制限
- 受信箱から添付できるのは、MP3・M4Aの50MBまで(既存の添付の上限のまま)。WAVや50MBを超えるメモは、受信箱には入るが、添付はまだできない。
- ボイスメモのコピペ取り込みは、この受信箱が動くまで残す。動いたら、画面から外す。
