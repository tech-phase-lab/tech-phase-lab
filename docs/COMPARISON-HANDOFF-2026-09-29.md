# PRO銘柄比較 — 引き継ぎ

## ユーザー承認
最大3社、PRO専用。銘柄入力→精査中→結論を最上部→数値・割安さ・成長性・注意点。低PERだけで割安判断する機能は禁止。最終目標は根拠付きの総合比較であり、今回の年次実績比較のみで完成とはしない。

## 今回実装
- /research/compare と /api/research/compare。2〜3社、重複不可、監視対象22社の入力・選択。
- サーバーPRO認証・有効期限確認、Cookie別no-storeレスポンス。画面は認証切れ時に消去。
- SEC companyfactsを並列取得し、正規化した小さな結果を1時間キャッシュ。レスポンス容量とタイムアウトを制限。利用者ごとのAPI有料契約は発生しない。
- 年次10-K/20-F標準タグ・同一報告通貨・同一提出書類・一致する期間だけで前年比、営業利益率、簡易FCFを算出。出典、期末、提出日、取得日時を保存して表示。
- 事業モデル/会計/通貨/期末が異なる、欠損・古いデータがある場合は順位を保留。年次売上増減率の順位を出す場合も、将来成長や割安順位とは明確に区別。
- 回答の生成演出のための不要な待機なし。実際の取得処理中に「精査中」。初回は数秒を超える可能性あり。
- PCサイドバー・ツールナビ・PROモバイルメニューに導線。

## 原則
TradingViewデータの抽出・スクレイピング・再配布なし。未取得数値の生成なし。比較不能を0点や0円で埋めない。FreeにPRO結果を配信しない。全社取得失敗時も成功分析に見せない。
