# RIZELの一言 — 保存・差し替え案（未実装）

承認前の文章は非表示。今回のホーム公開とは別の提案です。

## 保存場所

RESOLUTEのサーバー側DBに専用の文章台帳を作る案です。本文は日英別に
保存し、文章ID・版番号・下書き／承認済み／停止中・承認者・承認日時を
記録します。承認は文章の版に結び付け、編集しただけで承認済みの文章が
変わることを防ぎます。既存の購入権限の記録とは別テーブルにします。

## 差し替える方法

運営者専用画面に「RIZELの一言」を設け、文章を貼り付けてプレビューし、
「承認して公開」を押す方式を推奨します。コード編集や再デプロイは不要に
します。編集は新しい下書きとして保存し、再承認するまでは現在の承認済み版を
保持します。「非表示にする」「以前の承認済み版へ戻す」も用意します。

日本語と英語は別々に承認します。承認された版だけを配信し、AIは対象条件に
合う文章を選ぶだけで本文を書き換えません。1記事につき一言と補足1〜2点。
画面だけでなくサーバーでも運営者本人を確認し、変更履歴を残します。

この方式は提案段階です。DB変更・管理画面作成・公開操作はまだ行っていません。
