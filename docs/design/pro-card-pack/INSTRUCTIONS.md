# PRO紹介カードの改修と年額プランの追加

同梱の card-final.html(動くサンプル)と card-final.png(完成図)のとおりに、FREE会員に出ているPRO紹介カードを直してください。作り直しではなく、今の実装(app/research/account/account-view.tsx の planCard、free側)の修正です。
フォントは今のサイトのものを使ってください。サンプルの Noto は仮です。問題があれば飛ばして記録し、そのまま作業を続けてください。

## 1. カードの中身(上から順)
1. 王冠 + TECH PHASE PRO(今のまま)
2. 切り替えの行:左に「日本円 / 米ドル」、右に「月額 / 年額」。選択中は金色の文字と金の下線、未選択は灰色
3. 「年額」の真上に、金色の小さな吹き出しで「17%OFF」。しっぽは下向きで「年額」を指す。動きなし。タップは受けない(月額の操作の邪魔をしない)
4. 価格。年額を選んだときだけ、横に二重の打消し線で月額12か月分(35,760円 / 240ドル)を薄く出す
5. 「PayPalで申し込む」ボタン。ここから直接PayPalへ進む(今の確認シートは通さない)。光が数秒おきに左から右へ走る演出つき。端末の「動きを減らす」設定ではオフ
6. 「無料プランのすべての機能に加えて」+ 今のPRO機能の一覧(文言と並びは今のまま)
- 最初の選択は「年額」。通貨は海外判定があればドル、なければ円
- 月額/年額と円/ドルはカード上で即切り替え。ページ移動なし
- 表示する価格:円は 月2,980円(税込)/ 年29,800円(税込)、ドルは 月20ドル / 年200ドル
- 色の使い方:PRO版だけ金色。FREE側の画面には金色を使わない
- 禁止:NEWバッジ、見出しなどの「…」での省略(全文が収まるように折り返す)、カード内に自動更新や返金の説明文を並べること

## 2. カードの外の注記
FREEカードの下(カードの外)に、小さく中央で:
「PROプランは自動更新です。解約はマイアカウントからいつでも可能です。」
次の行に「利用規約 ・ 特定商取引法に基づく表記」(それぞれのページへのリンク)
今あるカード内の「料金と規約を確認してから、PayPalへ進みます。」は消す。

## 3. 年額プランの実装
PayPalに年額プランを作成済みです。月額と同じ仕組みで扱ってください。
- 日本円の年額:P-6LB71700PW597933CNL25JBQ
- 米ドルの年額:P-2664352661021644CNL25LQY
- 環境変数は今の月額(TECH_PHASE_PAYPAL_LIVE_PLAN_JPY / _USD)にならって、年額用を追加(名前は _JPY_YEAR / _USD_YEAR を提案。既存の命名に合わせて変えてよい)。services/tech-phase-billing/live-preflight.mjs の確認にも追加
- 申込みの作成(billingRequest の "create")に、期間(月/年)と通貨を渡し、サーバー側で通貨と期間からプランIDを選ぶ。クライアントからプランIDは受け取らない
- 同意の記録(acceptedTerms)は今の値のまま送る。同意の表示方法は弁護士に確認中なので、結果が出たら別途指示する
- 契約の確認画面(アカウント、billing/screen.tsx)は、年額の契約でも正しく出す:ラベルを「月額料金」から「料金」に、年額なら「29,800円 / 年」と表示、次回請求日は年1回
- 自動更新の停止、状態の照合(reconcile)、Webhookの処理が、年額の期間(1年)でも動くこと。月額を前提にした計算や文言が残っていないか確認する
- 年額は返金なし(規約に記載済み)。画面には出さない

## 3.5 FREE紹介カードの価格をそろえる
PROカードと並べたときに揃うよう、FREE紹介カードの価格表示をPROの価格と同じ作りにしてください(表示は「¥0」ではなく円表記にそろえる)。
- 表記:「0円」+ 小さく「/ 月」(PROの「2,980円 / 月(税込)」と同じ形。FREEは税込の表記なし)
- 数字のフォント・文字サイズ(48px相当)・太さ・行の高さ・単位との間隔・上下の余白は、PROの価格とまったく同じ値にする。2つのカードを並べて、数字の高さと位置が揃っていること
- 色はFREE版のまま(金色は使わない)。数字は白系、単位は灰色
- 切り替えやバッジは付けない。英語表示は「¥0 / month」(通貨はPROカードの選択に連動させず円のまま)
