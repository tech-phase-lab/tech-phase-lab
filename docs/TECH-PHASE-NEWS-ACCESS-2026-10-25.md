# ハイテク速報のFREE / PRO分離（2026-10-25）

方針：`TECH-PHASE-FREE-PRO-POLICY-2026-10-25.md`。
対象は既存の監視銘柄の速報配信。既存収集・翻訳・審査処理、連関マップ、テーマランキング、決済処理は変更しない。

## 実装

- サーバー側の会員判定でPROのみ既存の即時・要約付きニュースを配信。未ログイン・FREE・会員判定エラーは無料向けに限定する。URLのplan指定では切り替えない。
- FREEニュースは発表時刻から30分経過した見出しのみ。公式記事・ニュース・アナリスト速報・wireを合わせて新しい順に最大5件。決算結果は5件枠の対象外。
- FREEの見出しは専用のフィールドで送信。要約・本文・影響分析を付けず、既存の本文付き配列から対象記事を除去する。元記事の日本語見出しがない場合、要約を見出しへ転用しない。
- 日付しか分からない記事は、初回取得から30分待つ。発表時刻を捏造しない。未来・不正時刻は非公開。
- 同じURLの公式記事とwireは無料枠を重複消費しない。
- `/api/research/news`とホームの初期HTMLで同じ処理を適用。FREEの`/api/research/company-wire`から別途新着を取得できないようにする。
- 決算結果・経済指標結果・一般ニュース・市場情報を維持。目標株価の表示用APIは変更しない。アナリスト速報の配信制限と目標株価の表示を混同しない。
- 速報ページ・監視銘柄ページ・ホーム上部・新着表示が無料向け見出しに対応。スマホ下部の「速報」は残す。
- APIレスポンスは`private, no-store`と`Vary: Cookie`。旧ホーム表示キャッシュを再利用せず、新しい永続キャッシュには無料データだけを保存する。無料データへ切り替わった後は、以前読み込んだPROのwireを表示へ混ぜない。PROのメモリキャッシュはページ再表示の初期値として再利用しない。
- 案内文は「PROでは30分早く、要約付きで読めます」。無料ニュースの5件制限と決算の無料公開も明記。

## 運用上の範囲

- FREEの5件を全配信元から選ぶため、サーバーから既存wireを1回読む。wireが停止しても検証済みニュースと決算は配信する。wire取得の待機上限は2.5秒。追加のAI生成は行わない。
- 更新・会員判定は既存のポーリング時に行う。ブラウザへ過去に配信済みの内容をユーザーの端末から回収する機能ではない。
- 本番の実データ・実アカウントを使ったブラウザ受入は未実施。Railway接続・再認証・本番設定変更はしていない。
